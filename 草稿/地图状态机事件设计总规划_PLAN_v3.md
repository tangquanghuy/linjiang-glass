## 相对 v2 的修正清单

v2 的方向没错，坏在三处：**强度没有刻度**、**shop 口径与复审清单互相打脸**、**trigger 与分支门槛职责不分**。
六批 112 节点写下来实测出的问题，逐条修在这一版：

## 一、 硬红线（一票否决）

### 1. 结算字段白名单

写在 `结算` 里的东西只能来自这张表。不在表内的一律不许出现。

**世界**

- 年历、时间（朝 / 昼 / 暮 / 夜 / 深夜）
- 位置.区域（`大区域名·子区域名`，子区域名 = 节点 `name`，不加修饰）
- 位置.场所（仅无独立背景的小地点：试衣间、公厕隔间、歇脚长椅、观景崖边、日料包厢、自宅卧室）
- 位置.私密度（0~5，随场所改，不随整座山 / 整栋商场改）
- 事件池.当日事件

**玩家**

- 体力、金钱、同行（`string | null`）
- 背包.素材 / 消耗品 / 用品

**对象**

- 好感度 0~1000、顺从度 0~1000
- 心情（`开朗 | 害羞 | 委屈 | 发情 | 依恋 | 困倦 | 崩溃`，七值枚举，不许自造）
- 性经历：近期性经验次数 + 12 轴
- 生理：性欲度 0~100、体力 0~100、尿意 0~100、异常状态 `string[]`
- 开发度：口腔 / 胸 / 小穴 / 肛门。**只在正文按草稿晋升，不作 trigger，card 一律不写**

数值幅度见 §5.1。异常状态是自由字符串，但沿用既有值：
`微醺`、`蓝色花粉催情中`、`极度憋尿`、`深度昏睡`、`暗示中`、`寸止焦渴`。

#### 四条易错轴的判定标准（本轮 100% 出错，逐条给死线）

写完一条分支，拿这四把尺子量。量不过就是**没落到轴上**，属于空结算，必须改写或删掉。

**露出经验** —— 判据：**身上少了什么，具体到什么程度**。
- 算：全裸 / 真空（外衣底下一件不留）/ 下身脱光 / 上身赤裸 / 贴身底裤交出 / 只穿某一件器物 / 遮挡物中途被收走。
- 不算：脱一件外套、把外套抱在怀里、解开衣襟又拢上、把衣物「整理」一下。
- 反例（本轮被打回）：`让她把外套脱下抱在怀里，端着碗从这头侧身挤到卖蛋那摊` —— 脱外套什么都没发生，却记了 `露出经验+1`。

**凌辱调教经验** —— 判据：**有没有真的拘束或责罚动作**。
- 算：绳缚、捆在什么上、口枷 / 塞口、抽打（枝条 / 皮带 / 拍子）、滴蜡与灼热剂、罚跪、剥光后拘束放置。
- 不算：让她举着东西、捧着东西、端着东西、撑住某处、站着别动。**那是体力劳动，不是凌辱。**
- 反例（本轮被打回）：`让她把最满那只菜筐举在头顶，等车主从对面回来才准放下`、
  `不许她用篮子，要她双手捧着果子走到棚口，掉一颗就整垄重来`、
  `让她双手撑住沟沿把身子悬在地沟上方` —— 三条全是小学生罚站，却都记了 `凌辱调教经验+1`。

**盗摄经验** —— 判据：**拍到的东西本身是不是私密**。
- 算：睡中剥到腰下拍私处特写、剥光后用器材从下往上拍、赤身在灯下被一张张拍。
- 不算：她穿着全套衣物 / 制服 / 赛车服被拍。**镜头在场不等于盗摄**。
- 反例（本轮被打回）：`把车头的记录仪拧过来正对驾驶座，让她照常跑完这一局` ——
  她戴着头盔穿着全套赛车服，拍下来什么都没有。

**情趣扮演经验** —— 判据：**这场扮演有没有性维度**。
- 算：护士问诊触诊、精油推拿推到敏感处、装成猫狗四肢着地、顶替职务时身体处于被指定的状态。
- 不算：换身衣服讲一段话、背一套话术、报一遍流程。**那是才艺表演。**
- 反例（本轮被打回）：`让她挂上备用工牌站到沙盘后头，照销讲的话术把这个盘从头讲一遍` ——
  零性内容，却记了 `情趣扮演经验+1`。改法见 §3.5。

### 3. 禁止写进 card / 结算的伪字段

- 羞耻度、露出度、凌辱值、恋爱关系 flag、处女、高潮次数
- `口交侍奉经验`、`玩具绝顶经验`、`崖边亲昵经验`、`病房睡奸经验`、`密林青奸经验`、`录音经验`
- 任何把地点或成因叠进轴名的写法（`力竭睡奸经验`、`试衣间隐奸经验`）
- 英文碎片键：`outdoor_exposure_exp`、`oral_service_exp`
- 开发度档位、乳头 / 阴蒂等更碎部位

口交、体位、中出位置、玩具绝顶是**正文手法**，不是经验轴。
桌下口部侍奉：`sexAction` 可以写「提出桌底口部侍奉」，结算按是否插入打**隐奸或自慰**，口腔开发度由正文另判。

### 4. 不单开、但必须会归类的玩法

- **宠物 play**：项圈牵引 / 尾巴栓 → 道具；装成猫狗、碗里进食、四肢着地 → 情趣扮演；笼关 / 鞭打 / 罚趴 → 凌辱；牵出去给人看再叠露出。
- **放置 play**：绑住 / 口枷 / 剥光拘束着晾起来 → 凌辱；没绑只含着跳蛋遥控放着 → 道具；真空或当众晾着再叠露出。**不因时长重复 +1**。
- **高潮控制、酒后、被旁人看见**：不另开轴。酒后用异常状态「微醺」；旁人在场叠露出或性直播。
- **远程遥控、日常携带**：并入道具。直播中遥控再叠性直播。
- **车震** → 隐奸；**下药昏睡** → 睡奸；**暗示 / 洗脑** → 催眠奸。催眠与睡奸 **不双计**。
- **道具与凌辱不双计**：以绑打责罚为主场、顺带跳蛋只计凌辱；只戴项圈牵引只计道具。

一场可以打多轴，但必须**真的发生了多类行为**（全裸驾驶并录像 = 露出 + 盗摄），
不是因为「写得黄」就全加，也不是顺手把露出叠上去凑数量。

### 5. 题材红线

选题从 `XP大全_蓝灯_Ver1.5.md`（475 条）里挑，但下列条目**整类剔除，不进选题池**：

```
NTR / NTL / 轮奸 / 群体 / 一女多男 / 人外 / 异能 / 铜矿
```

## 二、 十条设计法则

编号沿用 v2，方便已有节点注释里的引用（`法则四`、`法则七` 等）继续有效。内容按实测改过。

### 法则一：card 是玩家行动指令。写死身体状态，不写动作分解

这条 v2 被读反了，是本轮 25 条低幼分支的总根源。切清楚两件事：

| 必须写死 | 一律不写 |
|---|---|
| 她身上到哪一步（全裸 / 真空 / 下身脱光 / 交出贴身底裤） | 体位链、肢体拉扯的分解动作 |
| 拘束物是什么、捆在哪（睡袋 / 麻绳 / 捆菜绳 / 帐杆 / 案板） | 射精位置与体内外结局 |
| 责罚用什么、打哪里（枝条抽臀 / 皮带 / 灼热剂抹遍） | 女方的对白、表情、声音 |
| 插入或含入了什么、开到什么档（跳蛋塞进体内、档位推到顶） | 「尝试提出 / 尝试推进 / 尝试悄悄」这类虚化前缀 |
| 什么条件才准停（到哪一摊、哪一局、哪盏灯灭、谁回来） | 微观怎么躲人（交给正文生成） |

正确：*让她真空套上外套，里面一件都不留，把今天做饭要的菜买齐*。
错误：*让她把外套脱下抱在怀里挤过去*（身体状态没写死，等于没有指令）。
错误：*褪去底裤抱上石栏悬空深入抱插*（写成了动作分解）。

强度写到哪一档，见 §3。

### 法则二：Play 概念颗粒度

- 错：*在垄道下达趴腿素股*（素股是正文手法，不是 card 概念，且没落轴）。
- 对：*书架死角隐奸*、*项圈宠物漫步*、*桌底口部侍奉*、*长椅睡奸*、*密林青奸*。

一条 sexAction 必须能念出题材名。念不出就是没写清。

### 法则三：H / 调教必须能念出题材名，禁止「肉体结合」

普通做爱有恋爱就能发生。地图事件的价值是题材：
试衣间隐奸、落日青奸、病房睡奸、诊疗扮演、公厕隔间隐奸、暴雨暗巷青奸、花粉暗示催眠奸、
靛缸凝视催眠奸、只留麦的性直播。

### 法则四：同节点机制 100% 异构，且事件密度有下限

- 单节点 **3~5 条**事件，核心机制不许重复。
- 每条事件 **至少 2 支 card 键**。只有一个 `pureLove` 键的事件等于没有机制，
  老档有 40+ 条这种流水账（`帮她把院子收拾好`、`帮她把门弄开`、`送到门口，等她开门再下楼`），全部要改或删。
- **同区不留第二条同成因**。青屏山已有长椅力竭睡奸，露营区的帐内睡奸就整条移出，
  不是换个招牌再写一遍。
- 宁缺毋滥的执行方式见 §3.4：**少写一支，不降强度**。

### 法则五：title / opportunity 是客观舞台，禁止剧透分支

- `title` = 地点 + 客观状态。对：*清晨薄雾笼罩的天然巨石*。错：*清晨薄雾下的巨石野战*。
- `opportunity` = 环境 + 可观察的生理 / 精神状态 + 道具是否在场。
- 道具只写「在场」：`遥控跳蛋在你背包里`、`安眠药在你背包里`。
  **禁止**写它怎么用、更禁止写已经用过：
  - 错：`包里若带着遥控跳蛋，现在用得上`（老档 xz_esports 原文，剧透分支）
  - 错：`女伴喝下了下药的水杯`（下药只写 mischief「向在场饮品动手」，opportunity 只写杯子在桌上）
  - 错：`反锁房门准备检查`
- 布局信息（摄像头装在哪、哪段没有）写进 `intro` 当客观事实，不要在 opportunity 里当旁白甩出来。

### 法则六：不代写女方台词、声音、具体款式

- 衣着只用泛化词：`衣襟`、`上衣`、`贴身底裤`、`外套`、`裤子`。
  地点提供的制服可以写来源（`院方发放的病号服`、`客栈备的粗布褂子`、`场里租的赛车服`），不写款式与拉扯。
- 禁止：肩带、晒痕检查、裙褶、纽扣拉扯、百褶裙。
- 禁止哼唧、哭泣攀附、并拢内扣喊主人。
- **注意与法则一不冲突**：`脱光`、`真空`、`下身脱光` 是身体状态，属于必须写死的那一栏；
  `蕾丝边的肩带滑下来` 是款式描写，属于禁止的那一栏。

### 法则七：一个舞台多条分支；分类贴在分支上，不贴在事件上

事件（title / opportunity / trigger）只是客观舞台，**禁止**在事件根上写 `分类: '纯爱'`。
分类贴在 `card` 的每一支上。键名是三大倾向，倾向不等于分类。

| 键 | 倾向（玩家怎么靠近） | 这支的 `分类` 按内容另标 |
|---|---|---|
| `pureLove` | 温情、守护、日常协助 | 通常 `纯爱`；采集置装打工是 `日常` |
| `mischief` | **规训、羞耻指令、拘束、责罚、盗摄、道具、下药** | 通常 `调教`；看护排泄是 `生理窘迫` |
| `sexAction` | 核心 Play | `特殊H` / `睡奸` / `催眠奸` / `调教`（扮演、凌辱为主场）/ `生理窘迫` |

**v2 在这里用了「恶作剧」三个字，v3 删掉。**
那个词直接生产出了下面这一批东西：举菜筐、捧草莓、撑沟沿、刮露水、戴铃铛端托盘、
脱一件外套、挂工牌背话术。`mischief` 不是恶作剧，是**规训**——必须对她的身体下一道明确的指令。

**mischief 三件套**（缺一件就是没写成，见 §3.1）：
① 她身上到哪一步 ② 谁在场、谁的视线 ③ 什么条件才准停

禁止 `footService` 等碎片键。三支不能是同一类侍奉的三个姿势。

#### 反例：栈桥日落（两支都是纯爱）

```javascript
// 错：事件根上写 分类:'纯爱'，mischief 只能挤出整理发夹
{
  title: '老轮渡栈桥的江边日落',
  card: {
    pureLove: '并排坐在栈桥边缘看货轮驶过 (好感度+20, 心情→开朗)',
    mischief: '扶住其肩膀在江风中为发丝整理发夹 (顺从度+15, 心情→害羞)'
  }
}
```

`整理发夹` 和 `并排看货轮` 没有机制差。**举菜筐、捧草莓、刮露水与它同级**，只是换了道具。

### 法则八：经验只许打 12 轴短名

奖励栏只写 `露出经验+1`、`隐奸经验+1`。禁止 `密林青奸经验`、`力竭睡奸经验`、`口交侍奉经验`。
打之前用 §1.2 的四把尺子量一遍，量不过就是空结算。

### 法则九：时段 × 人流 × 私密度，禁止违背现实

- 朝 / 深夜：林海、天台、空置自习室、露营坡 → 青奸、采集、熟睡、项圈夜行、催眠暗示。
- 昼：营业中的试衣间、门诊、满座自习室 → 隐奸、憋尿受验、桌下暗度。私密度 0~1 的大厅不做青奸。
- 暮：崖边、返程、定情 → 纯爱为主，露出可以到全裸（四周客观无人时）。
- 夜：夜市跳蛋巡游、暗巷暴雨、成人店、私汤、直播。
- 深夜：通宵睡奸、密林项圈、天台青奸、反锁诊疗 / 凌辱。
- 商场深夜已打烊就不要写试衣间逛街。**openHours 必须和事件时段、gather 时段自洽**
  （老档 qp_camp 的 gather 写「晨起帐顶有露」，openHours 却没有朝，露水永远采不到）。

### 法则十：先有真实地图，再问这块地上能发生什么

顺序不许反：先定这座城里**为什么会有这个点**（交通、购物、看病、打工、采集、租住），
`intro` / `draw` 必须能当旅游介绍。然后才问：这个功能、这行人流、这个私密度，会逼出什么冲突。
**Play 是地点的衍生物，不是选址理由。**

- 禁止为了跳蛋 / 绳缚 / 催眠专门开点（皮艺悬吊工坊、感官剥夺仓、隧道下层机房专供睡奸）。
- 同一功能不开第二家：私汤、成人店、通宵自习室全城各留一处，换招牌不算新节点。
- 试衣间、诊疗床、绿幕、样板间、休息舱是**场所**，挂在节点下面，不要做成节点名。
- **优先用这块地手边真有的东西当道具**：绑藤的枝条、捆菜的塑料绳、领口那管散热膏、
  扎染的麻绳、还在滴水的湿布、睡袋的拉链、车头的记录仪、直播舱的手部机位。
  这比一律掏背包里的跳蛋更像这块地，也天然避免形态复读。

写作顺序：节点身份 → intro / draw / 功能 / special → 这块地客观会有的 3~5 个冲突 →
title → trigger → opportunity → card → 用 §10 自检。

## 三、 强度刻度（本版核心）

v2 只说了「不要预写微观结局」，没说**该写到哪一档**。结果六批里出现了大面积
「机制不同、强度全无」的分支：轴记上了，念出来是儿童节目，不是 R18 系 SLG 的调教选项。
这一章就是刻度本身。

### 1. 刻度基准（三条标准样本）

下面三条是**校准过的基准线**。写任何 mischief 之前先念一遍这三条，对齐了再写。

```
露出          让她真空套上外套，里面什么都不留，去买今天做饭要的菜
              结算：顺从度+30, 露出经验+1, 心情→害羞

露出 + 盗摄    让她脱光一起全裸赛车，并用行车记录仪记录
              结算：顺从度+30, 露出经验+1, 盗摄经验+1, 心情→害羞

凌辱          让她脱掉裤子，用绑藤的枝条抽直接打屁股
              结算：顺从度+30, 凌辱调教经验+1, 心情→委屈
```

读出三条的共性：

1. **身体状态写死**：真空 / 脱光 / 脱掉裤子。没有一条含糊。
2. **任务照旧是日常**：买菜、跑一局、采果。羞耻来自「日常任务 × 极端身体状态」的反差，
   不来自把动作写细。
3. **动作是单一概念**：抽打屁股、全裸驾驶、真空外出。都是一个能念出名字的 Play，
   不是分解动作，也没有体位链。

### 2. mischief 三件套（缺一件就是没写成）

| | 内容 | 反面 |
|---|---|---|
| ① 她身上到哪一步 | 全裸 / 真空 / 下身脱光 / 上身赤裸 / 贴身底裤交出 / 塞进体内 / 被捆在什么上 / 被抽打哪里 | 没写身体状态，只写她拿着什么、走到哪 |
| ② 谁在场、谁的视线 | 摊主、司机、销讲、邻帐、下一组看房的人、拉着窗帘睡的人，隔多远 | 「四周无人」（那就没有羞耻来源了，除非本条走的是纯私密向） |
| ③ 什么条件才准停 | 到哪一摊、跑完哪一局、哪盏灯灭、谁回来、这缸上完色、镜子重新糊上 | 没有终止条件，指令悬空 |

### 3. 强度分档与顺从门槛

强度必须和 `顺从度` 门槛匹配。对照草稿的顺从阶梯定档：

| 档 | 顺从门槛 | 这一档能做什么 | 样例 |
|---|---|---|---|
| 轻 | 350~449<br>（娇嗔妥协） | 解开衣襟、隔衣抚触、戴上不外露的小件 | `提出在无人栈桥尽头敞开衣襟，只对江面和你露出` |
| 中 | 450~549<br>（专属让步） | 交出贴身底裤、真空外出、下身脱光、当面自慰、看护排泄、体内塞入并遥控 | `让她真空套上外套，里面一件都不留，把今天做饭要的菜买齐` |
| 重 | 550~649<br>（禁忌默契） | 全裸行动、全裸干活 / 驾驶、抽打、绳缚、口枷、拘束放置、灼热剂、剥光后被拍 | `让她脱掉下身趴到垄槽上，抽一根绑藤的枝条，每采完一格就在她臀上落一记` |
| 极 | 650+<br>（乐于承接起） | 全裸配项圈牵引外出、公开直播中的插入、多重拘束叠加 | `扣上项圈牵着绳让她赤着下身走过这几个拐折`（另需携带项圈） |

`sexAction` 的门槛另按 Play 定：
隐奸 / 青奸 `性欲度>=70~75` + `顺从度>=550`；睡奸 `体力上限:19` + `顺从度>=600`；
催眠奸 `异常状态含:'暗示中'` + `顺从度>=600`；性直播 `性欲度>=80` + `顺从度>=600`。

**门槛与强度不匹配是错的两个方向**：350 档写全裸是越阶，650 档写「脱一件外套」是浪费。

### 4. 形态池与轮换（防的是复读，不是防强度）

同一条轴写多了，真正会腻的不是强度，是**同一个形态词反复出现**。
所以每条轴维护一个形态池，**同一批里不出现两条同形**；换的是形态，不是把强度往下调。

| 轴 | 形态池（已用尽的形态换下一个，不要换成弱版本） |
|---|---|
| 露出 | 全裸站定 / 遮挡物中途被收走 / 全裸干活 / 全裸驾驶 / 真空外出 / 只穿单件器物 / 交出贴身底裤 |
| 凌辱 | 睡袋拘束放置 / 枝条抽打 / 皮带抽打 / 灼热剂涂遍加罚跪 / 麻绳捆在案板并刷染液 / 口枷加罚跪 / 绵绳反缚跪定 |
| 道具 | 体内跳蛋加遥控 / 项圈牵引 / 铃铛脚环 / 湿布蒙眼 / 眼罩触觉剥夺 / 直播中遥控 |
| 自慰 | 当面 / 寸止 / 对镜 / 对窗 / 败者惩罚 / 限时到顶 |
| 盗摄 | 睡中私处特写 / 车载记录仪 / 车灯下 / 直播舱手部机位 / 手机特写 |
| 排泄 | B超憋尿受验 / 让号重取 / 末班车厢忍完全程 / 林边并排 / 逼到失禁边缘 / 侧门单间反锁看护 / 正对面蹲下不许遮 / 坏门外抵门看护 |
| 睡奸（成因） | 输液镇静 / 夜班力竭 / 通宵赶早课 / 下田力竭 / 搬运力竭 / 泡汤泡晕 / 登山力竭 / 投安眠药 |
| 催眠（诱导手段） | 花粉气味暗示 / 随访手册问句引导 / 靛缸水面视觉诱导 |

**这条是本轮的另一个自纠**：初稿因为「交裤真空累计已用四次」而回避这类写法，
换成了更弱的替代（脱一件外套）。这个回避是错的。
**强度够的写法该复用**，换的是舞台、谁在看、交出去之后要她去做什么。

### 5. 「宁缺毋滥」的正确执行

法则四的这四个字，v2 没说怎么执行，结果被执行反了：
够不上强度时**塞了一个低幼版本进去凑键位、凑轴覆盖率**。

正确做法，按优先级：

1. 这支够不上强度 → **不写这支**，事件回到两支（`pureLove` + `sexAction`，或只有前两支）。
2. 整条事件除了日常没别的可写 → **不写这条事件**，节点回到 3 条。
3. 这个节点的私密度 / 时段 / 人流撑不起插入 → **整个节点不给 sexAction**。
   已有先例：`qp_glass`（玻璃栈道，验票存包、管理员按批次放人）、
   `pj_morning`（早市，privacy 1、只开朝时、路窄到侧身）。
4. 轴覆盖率不好看 → **就让它不好看**。`sexAction` 覆盖率维持在 **34%~40%**，
   不给每条事件都配一发。情趣扮演一批只有 1 条也可以。

绝不许做的：把强度调低来填满 `mischief` 键。

## 七、 节点 Schema

### 1. 字段

```javascript
{
  id, name, fullName, district, archetype, privacy, openHours,
  intro, draw, features, gather, special, events
}
```

- `features`: `{ canGather, canDate, canWork, hasShop }`。`hasShop` **只表示有店面设施**，供地图筛选。
- `gather`: `{ materials: string[], desc }` 或 `null`。
- `special`: `string[]`，**取代 v2 的 `shop`**，见下。
- `events`: 3~5 条。

`intro` / `draw` 密度：走进去能看见的空间、气味或声响、什么人在、哪个时段还剩什么。
能当旅游介绍。禁止砍成三句功能词，禁止写反面解释（`不是商场`）。

### 2. `special` 字段规范（v2 的 `shop` 已废除）

**为什么废除 `shop.items`**：它是价目表（`鸡蛋 6 元 / 按个`）。
AI 本来就知道菜场卖什么，而这块地卖什么 `intro` / `draw` 已经说完了，再列一遍是零信息量。
`shop` 这个名字也不再合适（它要承担的已经不止商店），改成 `special`。

> **注意**：这条与 `节点复审清单.md` 旧版 §4「shop 要列出可买的具名种类」**方向相反**。
> 以本节为准，复审清单已同步。

`special` 是字符串数组，一条一句，每节点 **1~3 条**。句式固定：

```
[什么条件] + [这里有什么 / 谁] + [什么功能]
```

**三条硬规则**

**【一】直白、功能性、≤60 字。**一句话说完「条件 + 有什么 + 什么用」。
不写人物性格，不写他笑不笑、肯不肯报名字，不写传闻的来龙去脉。

被打回的原文（都是在写小故事）：
- `这些东西凑起来能配出什么，他不管也不问` —— 回避说效果，等于什么都没讲
- `住过隔壁的人说半夜听得见里面有人翻身` —— 纯气氛，玩家读完不知道能干什么
- `泡过的人两种说法：有人沾枕头就睡死过去，第二天日上三竿才醒；也有人整夜发热翻来覆去，越泡越难受，非得有人搭手才消得下去` —— 三行小说，压成「药效不定，或整夜发热或直接睡死」就够

**【二】必须落到玩家能用的东西上**，四类任选：
① 可获得的素材 / 消耗品 / 用品 ② 可定制的衣装与束具
③ 可解锁的准入（场地、封路、圈子、无人时段）④ 可搭上的人（**只作货源或引荐人**）

**【三】只写类别与用途方向，不写死具名单品。**
写「安眠向的菌子」「甜香催情的花干」「助兴药」「遥控震动小件」，
不写「野生伞菌」「蓝色野生花瓣」「催情药」「无线遥控跳蛋」。
写死会让 AI 每次复读同一个词，玩家三五次就腻；类别化则每次可换名换形态，
具体叫什么、什么颜色、什么气味交给正文当场生成，归到背包哪一栏由结算判。
商品通名（眼罩、耳塞、润滑、避孕套、炭、防潮垫）本来就是店里在卖的东西，照写不算写死。

**另注意跨节点的串复读**：同一个类别串不要在多个节点逐字重复。
`催情向的干花瓣、催眠向的伞菌` 已在 `gl_market` 用过，其他能采山货的点要换词
（`安眠向的菌子`、`甜香催情的花干`、`晒干就是药铺收的货`）。

不写价目表，不写数值效果，不写 `私密度` / `死角` / `隐奸` 这类机制词，不剧透 card 分支。

**`special` 与 `features.hasShop` 解耦**：没有商业功能的节点（银行、公交站、城中村、

## 八、 事件写法与范本

### 1. 四格，以及 `trigger` 与 `门槛` 的职责切分

事件根只有：`id / title / 场所 / 优先级 / trigger / opportunity / card`。**不要事件级 `分类`。**

1. **title** = 地点 + 客观状态。选纯爱也不穿帮。
2. **trigger** = 这条事件**能不能出现**。
3. **opportunity** = 环境 + 可观察状态 + 道具是否在场。
4. **card** = 2~3 支，每支 `{ 分类, 选项, 门槛?, 结算 }`。

**v2 在这里自相矛盾**：§8.1 说 trigger 可以放顺从度 / 性欲度，
复审清单又说「pureLove 的整场 trigger 不要用顺从 / 性欲锁死」。v3 把职责切开：

| 放 `trigger`（事件能否出现） | 放分支 `门槛`（这一支能否选） |
|---|---|
| `时段`、`好感度`、`需同行` | `顺从度` |
| `体力上限`、`尿意`、`异常状态含` | `性欲度` |
| `需携带道具` | `背包有X`（与 trigger 的需携带道具呼应） |

**顺从度与性欲度一律不进 `trigger`。** 否则一条温情选项会被调教门槛挡住。
唯一例外：整条事件本身就是调教后果的**失神事件**（`trigger` 已含 `异常状态含: '暗示中'`），
此时可以带 `顺从度` 区间。

`需携带道具` 会连带锁住整条事件，所以**核心轴不要锁在背包里**。
性直播、青奸、睡奸这类要落地的轴，至少留一条不带 `需携带道具` 的事件承载。

### 2. `opportunity` 规格

- **≥60 字**。写足：环境 → 第三方在哪、隔多远 → 她的可观察状态 → 道具是否在场。
- 不剧透选了哪支，不写道具怎么用，不写作者旁白确认安全。
- 布局类事实（摄像头装在哪、哪扇门插销掉了、哪段没有灯）先在 `intro` 交代，opportunity 里当既成事实用。

对：

> 公厕门上的检修牌挂了很久，两扇门用铁链锁着，缝里能看见拆开的水箱。往下走到山门要四十分钟，往上到半山茶社还有三段石阶。步道两侧是齐腰的灌木和杂木，土径在这里拐进树影里，栈道那头暂时没有人上来。

错（电报体，老档原文）：

> 院子积水。她已经蹲下去看。邻院有动静。

### 3. 分类枚举（7 个，贴在分支上）

| 分类 | 这支在干什么 | 结算主轴 |
|---|---|---|
| 纯爱 | 拥吻、守护、牵手、陪伴 | 好感；通常不加性经历 |
| 日常 | 采集、置装、打工、家务协助 | 素材 / 金钱 / 体力 |
| 生理窘迫 | 憋尿、看护排泄、逼到失禁边缘 | 排泄 |
| 调教 | 露出指令、拘束、责罚、道具、扮演、自慰指令、盗摄、下药 | 露出 / 道具 / 凌辱 / 扮演 / 自慰 / 盗摄 |
| 睡奸 | 睡着 / 力竭 / 药物昏睡下的性交 | 睡奸 |
| 催眠奸 | 人醒着，已有暗示 | 催眠奸 |
| 特殊H | 隐奸、青奸、性直播 | 隐奸 / 青奸 / 性直播 |

同一事件**应该**混挂：崖边 = 纯爱拥吻 + 调教露出；长椅 = 纯爱守护 + 调教盗摄 + 睡奸。

## 九、 节点事件 ↔ 当日事件池

节点 `events` 是常驻舞台。每日换日：保留未过期常驻，清过期，再按关系生成 **2~3** 条当日事件。
梯度：低好感日常 / 中好感暧昧 / 高好感高顺从调教或特殊H / 低体力睡奸 / 暗示中的催眠奸。

玩家进入 `区域`（及可选 `场所`）且条件满足 → 状态改为 `可触发` → 正文推进并输出 `<突发事件>`。

池条目必须能一对一填草稿：

```text
事件ID: evt_qp_main_cliff
区域: 青屏山风景区·青屏山密林
场所: 观景崖边
标题: 黄昏落日下的观景崖边
分类: ['纯爱', '调教']          // 各分支分类的并集，供筛选；选定后本轮只走那一支
优先级: 60
状态: 待触发
条件:
  好感度: 450
  时段: ['暮']
简述: 与 opportunity 同口径的客观悬念，不剧透选了哪支
```

`条件` 字段只许：好感度、体力上限、尿意、异常状态、需携带道具、时段。
**顺从度与性欲度不进池条件**（它们是分支门槛，见 §8.1）。
不要在简述里写「可以在这里青奸」。

独行时：仅开放 `需同行: false` 的日常 / 采集；H 与调教默认不上池。

## 十、 交付前自检

### 0. 朗读测试（先于一切）

把每条 `选项` **单独念出来**，不看 title、opportunity、trigger、结算。

- 听得出这条在干什么吗：望风、看护排泄、真空买菜、全裸驾驶、枝条抽打、睡袋拘束、
  项圈牵引、帐内隐奸、长椅睡奸。
- 听不出就是没写成。听出来是「拿着东西走一段路」就是 §3.5 那批被打回的东西。
- **生理窘迫**必须出现排泄 / 憋尿 / 看护 / 脱到什么程度。
- **调教**必须是对身体下的指令，不是第二句温情，也不是干活。
- **纯爱**必须是正动作（牵手、望风、盖外套、看日落），禁止写成 H 的否定句
  （`不取项圈`、`按住不做下去`、`不在纸箱后面停`）。
- 选项必须是能说出口的完整短句。禁止把 Play 名、场所、收束词叠成电报
  （错：`下达隔纱露出对着巷`）。

### 1. 逐项检查表

**结构**
- [ ] 节点字段齐：`id/name/fullName/district/archetype/privacy/openHours/intro/draw/features/gather/special/events`
