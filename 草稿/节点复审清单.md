## 0. 朗读测试（必做，先于一切）

把每条 `选项` **单独念出来**（不看 title、opportunity、trigger、结算）。

- 必须听得出这条在干什么：望风、把尿看护、排泄禁止、解开衣襟、夹层隐奸、包厢隐奸、长椅睡奸、项圈跟随……
- **生理窘迫** 必须出现排泄 / 憋尿 / 把尿 / 看护 / 按压小腹。  
  错：`按着她的步频走完联通`（只像走路）。  
  对：`下达排泄禁止，按着小腹带她走完地下联通`。
- **调教** 必须是指令或恶作剧，不是第二条纯爱。  
  错：整理衣襟、整理发夹、不拍照只掖被角。
- **纯爱** 必须是正动作（牵手、望风、盖外套、看日落），禁止写成 H 的否定句。  
  错：`不在纸箱后面停`、`原路折回，不在芦苇里久留`、`不在巷里停`。

选项还必须是能说出口的完整短句。禁止把 Play 名、场所、收束词叠成电报；也禁止把「露出」单独当动词，后面再接「走完／对着某处」。  
  错：`下达隔纱露出对着巷`、`要她在温室过道里露出，把这栋走完`、`隔着薄纱要她对着巷子露出`。  
  对：`隔着薄纱，要她对着巷子解开衣襟`、`要她解开衣襟，沿温室过道走到头`、`罚她跪着，把这截玻璃栈道挪过去`。

## 1. 禁止套话（文风红线）

同一批里反复出现下列句式，报 P1，不要当成「谨慎」放过：

| 套话 | 例 |
|---|---|
| 来人／听见就停 | `来人就挡住`、`听见木板响就停`、`出声就停`、`走廊有人过就停` |
| 借物挡住 | `借芦苇挡住`、`借桥影挡住`、`借纸箱挡住`、`用外套挡住` |
| 纯爱 = 别在这儿停 | `不在纸箱后面停`、`不在滩上停`、`不在外机后面停` |
| 作者旁白确认安全 | opportunity 里 `她停下来听了一下，确认没有脚步` |
| 功能清单 intro | `餐饮层、外摆和中庭是这块地的客流。深夜卸货通道会清场。` |
| 反面解释 | intro/draw 写 `不是商场`、`不是私汤`、`试衣间戏在德泰` |

选项写法对齐法则一：简练动词 + Play 名。微观怎么躲人由正文生成。

衣着只用泛化词：`衣襟`、`贴身底裤`、`外套`。禁止肩带、晒痕检查、裙褶、纽扣拉扯。

## 2. 架空都市，南京／苏州只是原型

临江市是架空江南都市。选点借南京/苏州的**城市功能**（城中湖、水巷夜航、河西新城、大学城后街、南郊空港、过江码头），**正文禁止真实店名、行政区、地标**。

禁止写入节点 `name` / `intro` / `title` / `场所`：玄武湖、先锋书店、夫子庙、老门东、南京眼、江苏大剧院、金陵天地、元通、华采、国金、仙林、德基、禄口、中山码头、江北新区、建邺、钟山 等。

`district` 只能是临江八区：鼓岭区、明湖区、乌溪区、西洲区、落霞区、青屏山风景区、东塘区、雨石与浦江区。  
`name` 与位置子区域同字，不加「幽静」之类修饰。

## 3. intro / draw 密度

对齐 `city_mapdata_v2.js`：走进去能看见的空间、气味或声响、什么人在、哪个时段还剩什么。能当旅游介绍。

- 错（提纲）：`西洲河南岸的购物中心，贴着写字楼。餐饮层、外摆和中庭是这块地的客流。`
- 对（有人流和闭店后的地）：玻璃连廊、工牌、遮阳伞、喷泉、油烟、闭店后卷帘和纸箱。

禁止为了「不像 AI」把 intro 砍成三句功能词。

## 4. 法则十：先地图后 play

- intro/draw 先写这座城为什么会有这个点。Play 是衍生物。
- 禁止为情趣开点：皮艺悬吊工坊、感官剥夺仓、隧道机房专供睡奸。
- 同一功能不开第二家（换招牌不算新节点）。已占用见文末对照表。
- 试衣间 / 诊疗床 / 绿幕 / 存衣袋是**场所**，不要当节点名。
- **选项写用途，店货写具名种类。** 日常选项只写来这里干什么：置装、用餐、配药、买日用品。禁止把工序写进选项。shop 要列出可买的具名种类（连衣裙、米面、安眠药、口塞），不要只留「日用品」「成衣」一个笼统词，避免正文只会写跳蛋和矿泉水。
- **玩法具名**仍对齐草稿全名：跳蛋、项圈、眼罩、催情药、利尿药、便当、矿泉水、比基尼、护士服，以及门槛里的细铃铛脚环、避孕套、荧光记号笔、防水创可贴。
