# Glass HUD 页面与变量信息架构

## 1. 当前主状态栏

主状态栏只保留“行动中需要持续看见”的信息：

- 世界位置：`/世界信息/位置/区域`、`/世界信息/位置/场所`
- 同行状态：`/玩家信息/同行`
- 金钱：`/玩家信息/金钱`
- 日期与季节：`/世界信息/年历`
- 时钟与时段：时钟值 + `/世界信息/时间`
- 羁绊总览与角色卡摘要

原先位置条和时间列各显示一次“夜”，信息重复。现在位置条右侧改成同行状态：

- `同行 == null`：显示“独行”
- `同行 != null`：显示“同行 · 角色名”
- “夜”只保留在 `20:45` 下方，和月亮图标组成完整时间语义

## 2. 页面层级：采用双层结构

### A. 上方速览（默认角色详情）

点击角色卡后，在主状态栏上方展开，不遮挡底部 HUD。

适合展示：

- 角色立绘、姓名、心情、当前位置
- 羁绊：好感度、顺从度
- 生理：性欲度、体力、尿意
- 湿润、异常状态
- 最近记录

原因：这些都是当前行动决策需要快速查看的信息。保留主状态栏后，可以直接连续点击不同角色切换，不需要反复退出页面。

### B. 全屏工作区（密集信息）

从上方速览点击“查看完整档案”后进入近全屏玻璃页面。

适合展示：

- 完整角色档案
- 性经历全部计数与里程碑
- 背包、素材、消耗品
- 当日事件池与触发条件
- 羁绊总览
- 设置

原因：这类信息字段多、需要筛选或对比，放在上方窄区域会拥挤，也会破坏主场景的阅读节奏。

## 3. 变量到页面的映射

### 主状态栏

| 区域 | 变量 |
|---|---|
| 位置条 | 世界信息.位置.区域、世界信息.位置.场所、玩家信息.同行 |
| 数值行 | 玩家信息.金钱、世界信息.年历、世界信息.时间 |
| 角色卡 | 对象信息.羁绊.好感度、对象信息.羁绊.心情 |
| 红点提醒 | 世界信息.事件池.当日事件中状态为“可触发”的数量 |

### 角色上方速览

| 模块 | 变量 |
|---|---|
| 羁绊 | 好感度、顺从度、心情 |
| 即时状态 | 性欲度、体力、尿意、湿润、异常状态 |
| 最近动态 | 最近性行为或最近普通互动记录 |

### 角色完整档案

建议做三个页签：

1. **状态**：羁绊 + 生理 + 异常状态
2. **经历**：处女、做爱次数、高潮次数、户外露出经验、排泄调教经验、道具调教经验、暗处隐奸经验、野外青奸经验、力竭睡奸经验、口交侍奉经验、情趣扮演经验、玩具绝顶经验、最近性行为
3. **事件**：与该角色相关的可触发、待触发、已完成事件

经历页不要把十几个数字一次铺满首屏。推荐按“基础 / 场景 / 调教 / 最近记录”分组，并突出刚变化的字段。

### 当日事件页

- 每条事件显示：分类、优先级、状态、区域、场所、简述
- 默认排序：可触发 > 优先级 > 距离当前区域
- 触发条件默认折叠，点击后展开
- 主状态栏只显示红点，不显示完整条件

### 背包页

- 左侧分类：全部、素材、消耗品
- 主区使用物品卡网格
- 素材显示来源与描述
- 消耗品显示效果类型、药效、数量与描述
- 玩家体力放在侧栏底部，作为行动资源提示

## 4. 当前交互入口

- 点击角色卡：打开上方角色速览
- 点击角色卡右上角星标：置顶/取消置顶
- 点击“详细”：打开羁绊总览
- 信件按钮：打开当日事件
- 记事按钮：打开背包
- 设置按钮：打开界面设置
- `Esc` 或右上角关闭按钮：关闭当前页面

## 5. 后续接入真实 MVU 数据

目前 `src/data.js` 使用示例数据完成视觉与交互框架。接入时建议保留组件需要的视图模型，把原始路径统一转换：

```js
const viewModel = {
  world: read('/世界信息'),
  player: read('/玩家信息'),
  characters: read('/对象'),
};
```

不要让页面组件直接散落读取十几个路径；先在数据适配层处理默认值、空数组、数值范围和字段缺失，再交给 UI 渲染。
